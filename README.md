# 幻獸們 MVP - 44幻獸修正版

本版修復上一版核心函式被誤刪造成的載入錯誤。

- 44隻幻獸：普通32、稀有8、幻彩4
- 火／水／風／土主池各10隻（8普通＋2稀有）
- 光／暗各2隻幻彩
- 火、風蛋對應光幻彩；水、土蛋對應暗幻彩
- 圖鑑記錄累積獲得隻數
- 成長90%以上顯示即將孵化
- 元氣納入孵化偏好
- 親密度50為偏好分水嶺
- 幻彩需親密度>80，且飽食／心情／元氣至少兩項>80，之後才有4%機率


## 介面與互動更新
- 成長狀態顯示順序改為：飽食度、心情、元氣、親密度、成長值
- 休息：元氣 +30、飽食度 -20、心情 +4、親密度不增加
- 玩耍：心情 +20、親密度 +12、元氣 -20、飽食度 -12
- 餵食：飽食度 +30、心情 +5、元氣 -5、親密度不變
- 狀態提示移至培育區上方
- 每次新培育時，狀態提示重設為「蛋正在孵化……」
- 互動按鈕寬度增加約 1.5 倍
- 選蛋與培育室僅顯示蛋名，不再顯示屬性／池提示

## 修正
- 選蛋按鈕改用 addEventListener 綁定，避免內嵌環境無法觸發 inline onclick
- 餵食新增親密度 +4
- 餵食目前效果：飽食 +30、心情 +5、親密度 +4、元氣 -5、成長 +14

## 手機版修正
- 選蛋區改為手機優先排版
- 600px 以下固定單欄顯示 4 顆蛋
- 980px 以下改為雙欄
- 強化 iPhone Safari 按鈕顯示與點擊區
- 加入 viewport-fit=cover 與 safe-area 支援
- 強化 screen-start 顯示邏輯，避免 hidden 狀態殘留

## iPhone Safari 相容性修正
- 修正依賴 HTML id 自動成為 JavaScript 全域變數的問題
- 所有主要 UI 元素改為 document.getElementById 明確取得
- 事件綁定增加 null 檢查
- 修正 Safari 在 render() 前腳本中斷，導致選蛋區空白的問題


## 孵化規則重構：資格池 + 權重
- 不再讓整個蛋池全部參加抽選。
- 先依培育結果判定「有資格孵化」的幻獸，再在合格者中加權抽選。
- 單一互動占 70% 以上時視為極端培育，會進一步強化同一路線結果。
- 親密度 50 是主要分水嶺，高親密與低親密會開啟不同候選。
- 若特殊數值組合導致沒有候選，系統只會使用 1～2 隻最接近目前培育方向的備援幻獸，避免整池亂抽。

### 主要資格
- 餵食型：親密度 >=50、餵食最多、飽食度 >=65
- 玩耍型：親密度 >=50、玩耍最多、心情 >=65
- 休息型：親密度 <50、休息最多、元氣 >=65
- 高飽食型：親密度 >=50、飽食度 >=85、餵食最多
- 高心情型：親密度 >=50、心情 >=85
- 高元氣型：依幻獸分為高親密／低親密路線
- 高親密型：親密度 >=70
- 低親密型：親密度 <50
- 均衡型：親密度 >=50，三種互動皆至少一次，且最大與最小次數差 <=2


## 超量互動懲罰
### 過度餵食
只有在「按下餵食前」飽食度已經是 100 時觸發：
- 心情 -10
- 親密度 -8
- 元氣 -5
- 成長值仍 +14
- 飽食度維持 100

若飽食度原本低於 100，即使這次餵食剛好升到 100，也不會觸發懲罰。

### 過度玩耍
只有在「按下玩耍前」心情已經是 100 時觸發：
- 親密度 -10
- 飽食度 -12
- 元氣 -20
- 成長值仍 +13
- 心情維持 100

若心情原本低於 100，即使這次玩耍剛好升到 100，也不會觸發懲罰。


## 元氣滿值休息規則
若「按下休息前」元氣已經是 100：
- 元氣維持 100
- 飽食度不變
- 心情不變
- 親密度不變
- 成長值不變

只有元氣低於 100 時，休息才會套用原本的數值變化。


## 培育期延長
- 餵食：成長值 +8
- 玩耍：成長值 +8
- 休息：成長值 +10
- 過度餵食／過度玩耍時也使用相同的新成長值
- 目的：讓玩家有更多回合經營親密度、心情、飽食度與元氣


## 培育期第二次微調
實測 8／8／10 時，最高親密度仍只有 76，因此改為：
- 餵食：成長 +7
- 玩耍：成長 +7
- 休息：成長 +9

經全路徑模擬後，最高親密度可達 84，已能符合「親密度 >80」的幻彩前置條件。

## 火蛋孵化平衡修正
- 燼爪貓：不再要求「玩耍必須最多＋親密度 >=50」；改為玩耍占有效互動至少 35%，且心情 >=65。
- 赤焰壁虎：改為親密度 <50 且元氣 <50，避免所有低親密培育都流向同一隻。
- 其餘資格池、幻彩條件與成長數值維持不變。

## 火花鼠平衡修正
- 火花鼠改為：親密度 >=60 且元氣 <70 才有資格進入候選池。
- 符合上述條件時，另給予少量權重加成。
- 其他火系幻獸與幻彩規則不變。

## 炎脈山貓平衡修正
- 最終資格：親密度 >=63、玩耍至少 3 次、元氣 <70。
- 符合條件後給予適度額外權重。
- 其他幻獸條件不變。

## 水蛋孵化平衡修正
- 浪紋企鵝：玩耍占有效互動至少 35%，且心情 >=65。
- 溪語蛙：親密度 <50 且元氣 <50。
- 雨鰓螈：親密度 >=60 且元氣 <70，並給予適度權重加成。
- 其他水系與幻彩規則不變。

## 風蛋孵化平衡修正
- 風鈴狐：玩耍占有效互動至少 35%，且心情 >=65。
- 旋葉倉鼠：親密度 <50 且元氣 <50。
- 旋風雀：心情 >=85、玩耍至少 3 次、親密度 >=55，並給予適度權重加成。
- 其他風系與光幻彩規則不變。

## 森／岩土蛋孵化平衡修正
- 泥團河馬：親密度 <50 且元氣 <50。
- 陶甲小熊：親密度 >=60 且元氣 <70，並給予適度權重加成。
- 岳冠鹿：三種互動次數差距 <=3，並稍微放寬孵化狀態門檻；符合時增加權重。
- 其他岩土系與暗幻彩規則不變。


## 圖鑑分區細化
- 新增「全部／火／水／風／森」圖鑑分類切換。
- 「全部」會依火、水、風、森四區依序顯示，不再把 44 隻混成同一排。
- 每一區顯示總收集進度，以及普通／稀有／幻彩的子進度。
- 火、風系共用兩隻光幻彩；水、森系共用兩隻暗幻彩。
- 共用幻彩只需實際取得一次，相關兩個圖鑑分區會同步解鎖。
- 保留「已獲得 X 隻」累積數量。


## 幻彩圖鑑卡片視覺強化
- 所有「幻彩」格子新增七彩霓虹風格。
- 使用彩虹漸層邊框、柔和發光、流光掃過效果。
- 已解鎖與未解鎖的幻彩格子都保留特殊感，但未解鎖會較低調。
- 不影響普通／稀有卡片樣式與既有圖鑑功能。


## 圖鑑第二次細化
- 新增獨立「🌈 幻彩」頁籤。
- 火／水／風／森各系主圖鑑改為 8 普通 + 2 稀有，共 10 隻；幻彩不再混入各系卡片區。
- 各系仍顯示「可額外孵化幻彩 X / 2」提示。
- 幻彩頁集中顯示 4 隻幻彩，並分別顯示光幻彩／暗幻彩收集進度。
- 已收集的幻彩卡片新增閃爍星光粒子；未收集時保留低調七彩霓虹框。
- 遊戲一開始即顯示完整圖鑑，即使尚未收集任何幻獸也能瀏覽。
